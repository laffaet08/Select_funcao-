# 🍎 Banco de Dados - Avaliação da Cantina

Este projeto contém o script SQL para criação e análise do banco de dados da cantina. O objetivo é registar o consumo e as avaliações dos utilizadores por turno (Manhã, Tarde e Noite).

## 🚀 Conteúdo do Projeto

O ficheiro `ATIVIDADE_2310.sql` inclui:
- Criação da base de dados (`cantina`) e da tabela `avaliacao`.
- Inserção de dados de exemplo sobre consumo, notas e sugestões.
- Consultas SQL com filtros (`WHERE`, `IN`), contagens (`COUNT`) e agregações (`SUM`, `AVG`, `MAX`, `MIN`).

## 🛠️ Como Executar

1. Abre o teu gestor de banco de dados (ex: MySQL Workbench, DBeaver ou phpMyAdmin).
2. Executa o ficheiro `ATIVIDADE_2310.sql` para criar a estrutura e inserir os dados.
3. Executa as consultas no final do script para analisar as estatísticas de vendas e notas.
